# Relatives Deck Projects

This repository stores the online practice and assessment projects connected to the Relative Clauses slide-deck series.

## Projects

### Deck 1 — Core Foundations Test
Path: `apps/deck-1-test/`

A 15-minute online comprehension test for the grammar taught in Deck 1.

Features:
- full-name entry on the welcome screen
- 30 scored questions
- 15-minute timer
- 0–100 automatic score
- answer review showing right/wrong responses
- concise grammar feedback after submission
- GitHub-backed result logging through a serverless API
- responsive desktop/mobile UI

Future Deck 2–4 apps should live under `apps/` as separate projects.
